本项目用于记录个人在网络爬虫与逆向工程领域的学习历程与实战练习。**本人主攻 Web 端高强度逆向与微信小程序（Mini-Program）逆向**，专注于复杂加密算法还原、协议分析以及反爬虫机制对抗。

---

## 🛠️ 技术栈与核心方向

在日常的逆向工程实践中，主要涉及并钻研以下技术领域：
* **核心定位**：Web 端 JS 逆向分析、小程序全量反编译与动态调试。
* **算法还原与混淆对抗**：AST (抽象语法树) 反混淆解密、JSFuck 乱码还原、魔改对称/非对称加密逆向。
* **环境检测对抗**：基于 Proxy 代理的高仿真浏览器沙箱补环境、浏览器/设备指纹（Fingerprinting）伪造。
* **数据反序列化**：主流平台微服务自定义协议逆向、Protobuf (Protocol Buffers) 协议数据流解析。

## 📌 逆向实战练习课题

以下为当前重点攻坚和持续迭代的国内外主流平台加密参数分析：

| 平台名称 | 核心加密参数 / 课题 | 核心攻坚方向与技术要点 |
| :--- | :--- | :--- |
| **抖音 (Douyin)** | `a_bogus` 算法还原 | 高强度 JS 混淆还原、浏览器环境检测对抗与签名补环境 |
| **抖音直播** | 直播间数据 `sign` 值解析 | Protobuf 协议逆向、二进制数据流反序列化与解密 |
| **美团 (Meituan)** | `mtgsig` 请求签名 | H5guard 签名机制追踪、API 请求头特征识别与环境 Mock |
| **京东 (JD)** | `h5st` 签名分析 | 核心魔改加密算法解析、滑块验证码行为轨迹风控对抗 |
| **拼多多 (PDD)** | `anti-content` 参数 | 风控打点数据还原、高强度代码逻辑混淆深度剥离 |
| **小红书 (XHS)** | `x-s`  动态签名 | 请求头动态签名生成、设备指纹及账号风控策略链路拆解 |
| **同程旅行** | `user-dun` 请求头 | 登录态全生命周期校验、网络请求流反爬特征安全追踪 |
